# 模型输入契约

先读取实际注册与成品，确认玩家模型路径、bodygroup 名称和索引、各状态语义与子网格、实际骨名、独立装备 prop 及 skin/材质映射。状态 0 不必然是穿戴态，状态数量不能代替语义判断。

已有 prop 则复用并检查模型文件族、材质、碰撞和原点；没有 prop 时按 [独立装备提取](equipment-props.md) 自行从已有工程或反编译输入提取、制作碰撞并编译。人物分组不能独立隐藏目标装备时，按 [bodygroup 拆分](bodygroup-split.md) 处理后同步 Lua。

模型文件或必要源资产确实缺失时索取必要输入；缺工具时按 [环境配置](environment.md) 定位。不能把未制作的 prop 或未验证的分组映射视为完成。已有可靠工程优先使用，不为形式完整而重复反编译。
